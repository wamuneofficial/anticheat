# anticheat (шлюз)

Это публичный статический шлюз к дашборду Anti-Cheat CF, который работает
на ноутбуке владельца. Сам дашборд и все данные остаются в приватном
репозитории `anti-cheat-cf` — здесь только страница-редирект.

Как это работает: `index.html` читает `status.json` из этого репозитория
(текущий адрес тоннеля cloudflared или `null`, если ноутбук выключен),
проверяет, что тоннель отвечает, и либо перенаправляет на дашборд, либо
показывает сообщение "Сервер выключен".

Файл `status.json` обновляется автоматически скриптом `deploy/start_public.sh`
из приватного проекта `anti-cheat-cf` — вручную его редактировать не нужно.

Страница опубликована через GitHub Pages по адресу:
https://wamuneofficial.github.io/anticheat/
